**File 1: `src/utils/supabase/__tests__/middleware.test.ts`**

Test stubs covering:
- `vi.mock("@supabase/ssr")` to mock `createServerClient`
- **Test: "writes refreshed cookies to both request and response when setAll is called"** -- Arrange: mock `createServerClient` so that when `setAll` callback is captured and invoked with test cookies and headers, assert that `supabaseResponse.cookies.set` is called for each cookie AND the response headers include `Cache-Control: private, no-cache, no-store, must-revalidate, max-age=0`. This verifies the dual cookie-write pattern (AUTH-01, D-01, D-04).
- **Test: "applies cache-control headers from setAll second argument to response"** -- Arrange: invoke the captured `setAll` with `headers = { "Cache-Control": "private, no-cache, no-store, must-revalidate, max-age=0", "Expires": "0", "Pragma": "no-cache" }`. Assert these exact headers appear on the returned response (AUTH-01, T-1-02).
- **Test: "redirects to /auth/login with reason=session_expired and next param when session is missing on /dashboard path"** -- Arrange: mock `getClaims` to return `{ data: { claims: null }, error: { message: "Auth session missing" } }`, request URL `http://localhost/dashboard/mycca`. Assert: response status 307, Location header contains `/auth/login`, contains `reason=session_expired`, contains `next=%2Fdashboard%2Fmycca` (D-03, D-05, D-06).
- **Test: "redirects unauthenticated user from /dashboard to /auth/login with reason and next"** -- Arrange: mock `getClaims` to return `{ data: { claims: {} }, error: null }` (no `sub`), request URL `http://localhost/dashboard/settings`. Assert: redirect to `/auth/login?reason=session_expired&next=%2Fdashboard%2Fsettings` (D-03, D-05).
- **Test: "allows auth page requests to proceed when session is missing"** -- Arrange: same error mock, request URL `http://localhost/auth/login`. Assert: response is not a redirect (status 200).
- **Test: "redirects authenticated user away from /auth to /dashboard"** -- Arrange: mock `getClaims` to return valid claims `{ sub: "user-123" }`. Request URL `http://localhost/auth/login`. Assert: redirect to `/dashboard`.
